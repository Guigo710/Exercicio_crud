# 📋 Exercicio CRUD — Gerenciador de Clientes

Projeto de uma **aplicação web simples de CRUD** para cadastro e visualização de clientes, desenvolvida com **HTML, CSS e JavaScript**, funcionando totalmente no front-end.  
A simple **CRUD web application** for client registration and visualization, built with **HTML, CSS, and JavaScript**, running entirely on the front-end.

🔗 **Demo online | Live demo:**  
https://exercicio-crud.vercel.app/

---

## 📌 Sobre o projeto | About the project

O projeto consiste em um **gerenciador de clientes**, onde o usuário pode preencher um formulário com nome, e-mail e data de nascimento e visualizar os dados em uma lista/tabela logo abaixo.  
Não há integração com backend ou banco de dados — os dados são manipulados diretamente no navegador.

This project is a **client manager**, where users fill out a form with name, email, and birth date and see the data displayed in a list/table below.  
There is no backend or database integration — data is handled directly in the browser.

## 🚀 Como funciona | How it works

1. Preencha os campos **Nome**, **E-mail** e **Data de Nascimento**.  
   Fill in the **Name**, **Email**, and **Birth Date** fields.

2. Clique em **Salvar Cliente** para cadastrar.  
   Click **Save Client** to register the client.

3. O cliente aparece na lista logo abaixo.  
   The client appears in the list below.

4. Utilize as opções **Editar** ou **Excluir** para gerenciar os registros.  
   Use the **Edit** or **Delete** options to manage the records.

5. Os dados permanecem salvos mesmo após fechar o navegador.  
   The data remains saved even after closing the browser.
